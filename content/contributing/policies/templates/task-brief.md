# Task brief template

Use only when a new task or delegation is already authorized. Read the
[coordination policy](../coordination.md) and reuse an existing owner when applicable.
Remove fields that do not help the bounded assignment.

```text
Outcome: Concrete behavior or artifact to deliver.
Owner and scope: Existing task, checkout/worktree and exclusively owned paths.
Model and effort: Explicit allocation; named difficult problem for Astra/Extra High.
Context: Agreed design/contract and current evidence; relevant policy/skill paths only.
Implementation: Required behavior and interfaces to coordinate with other owners.
Preservation: Existing data, runtime and unrelated work that the change must preserve.
Verification: Appropriate commands and observable acceptance; disposable state if needed.
Handoff: Changed files, evidence, remaining limitations and integration owner.
```

The receiving agent reads the relevant skills itself and reassesses if scope changes.
A dispatch acknowledgement is not implementation progress or acceptance.
